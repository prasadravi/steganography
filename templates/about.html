About this Project

This project demonstrates a hybrid framework combining AES encryption, image synthesis mapping and fragile watermarking to deliver secure communication without traditional LSB embedding. The UI contains pages for registration, search, friend requests, chat and a decryption workflow for stego images.

Key ideas
  • AES encryption for message confidentiality.
  • Image-synthesis mapping as an alternative to direct embedding.
  • Fragile watermarking to detect tampering and ensure integrity.
